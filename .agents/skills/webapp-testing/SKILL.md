# Webapp Testing Standards

## Testing Protocol
- Comprehensive unit tests in `tests/components.test.tsx`.
- Test every user interaction: copy email, category filters, navigation links, and responsiveness.
- 100% test pass rate required on `bun test` before any deployment.

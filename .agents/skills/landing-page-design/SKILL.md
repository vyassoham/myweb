# Landing Page Design

## Architecture
- **Above-The-Fold**: Status badge + H1 Name + dynamic role ticker + 2-sentence bio + primary CTAs + social links.
- **Momentum Flow**: Hero -> Featured Projects -> Open Source Core -> Technical Skills -> Contact.
- **Conversion Triggers**: Prominent resume download button, direct GitHub repo links, live availability pill.

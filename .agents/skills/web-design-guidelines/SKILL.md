# Web Design Guidelines

## Standards
- Minimum tap target size: 44x44px.
- Focus rings visible for keyboard users (`focus-visible:ring-2 focus-visible:ring-indigo-500`).
- Content scannability: bold key metrics, descriptive link labels (avoid 'click here'), clear visual anchors.

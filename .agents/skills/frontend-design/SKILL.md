# Frontend Design Mastery

## Core Philosophy
1. **Typography Hierarchy**: Use fluid clamp sizing, strict vertical rhythm (8px baseline), and max 2 typefaces (Display + Body).
2. **Color Palette Rhythms**: 60-30-10 rule. 60% dominant background (Obsidian #07070a), 30% structural surface (#13131e), 10% high-energy accent (#6366f1, #06b6d4, #10b981).
3. **White Space & Breathing Room**: Generous padding on section blocks (clamp(80px, 12vh, 160px)), keeping reading columns constrained to 65-75ch.
4. **Micro-Visual Delights**: Radial glow meshes, subtle borders (rgba(255,255,255,0.08)), custom cursor/hover affordances, and zero unstyled elements.

# Interactive Portfolio Guidelines

## Essential Elements
1. **Interactive Showcase**: Category filters (Systems, AI, Data), live GitHub metrics, and direct source links.
2. **Open Source Proof**: Dedicated deep-dive into upstream PRs with commit hashes, test results, and impact statements.
3. **Zero Friction Contact**: 1-click email copy with instant visual checkmark feedback.

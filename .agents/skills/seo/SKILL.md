# SEO & Search Discoverability

## Requirements
- `robots.txt`: `Allow: /` with Sitemap directive.
- `sitemap.xml`: Complete canonical URLs with priorities.
- `layout.tsx` Metadata: Title, Description, Keywords, OpenGraph type 'website', Twitter summary_large_image, canonical URL.
- JSON-LD Structured Data: Schema.org `Person` with jobTitle, worksFor, alumniOf, sameAs social links.
